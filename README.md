# odin-recipes

This project is a demonstration of the HTML abilities I have learned the past week through The Odin Project by writing the HTML documents of a recipe website.

Objects of this project:
    1. Ability to work with Git and Github.

    2. Writing meaningful commit messages, and commiting early and often.

    3. Using the right structure in an HTML file.

    4. Making proper use of a wide variety of popular HTML tags such as <strong>, <em>, <a>, <img> and etc. their attributes.
